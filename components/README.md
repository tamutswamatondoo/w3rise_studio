# Components Directory

This directory houses modular UI components for W3rise Studio.

## Planned Modular Components:
- `Navbar`: Semantic responsive header with atmospheric glass backdrop and interactive state indicators.
- `Hero`: Editorial lead with buttery hover primary CTA and smooth natural lighting.
- `FeaturedWorks`: Masonry grid and category filter pills (*All, Branding, Digital Experience, Strategy, Engineering*).
- `CoreServices`: Modular interactive capability cards (Brand Identity, Full-Stack Craft, Creative Direction, Interactive Experiences).
- `Footer`: Deep Chocopie `#432f2e` background with light typography and newsletter/social blocks.
