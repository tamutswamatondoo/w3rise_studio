# W3rise Studio

> *"Where strategy, design, and code converge into complete digital mastery."*

Elite, performance-driven digital agency website for **W3rise Studio**, engineered with a strict natural color hierarchy and modular architecture.

## Natural Color Palette Hierarchy
- **Chocopie (`#432f2e`)**: Rich organic grounding base — deep background sections, footer, high-contrast editorial headings.
- **Blue (`#c4dae8`)**: Airy atmospheric canvas — secondary container blocks, subtle negative space accents, section panels.
- **Butter (`#feefb8`)**: Luminous accent tone — warm interactive highlights, active state indicators, subtle glowing details.

## Project Structure
```text
w3rise-studio/
├── assets/         # Static assets, SVG icons, vectors, and brand media
├── components/     # Modular HTML/JS UI components
├── src/            # Application scripts and client-side logic
├── styles/         # Design tokens, reset, typography, and module stylesheets
├── index.html      # Mobile-first semantic entry point
└── package.json    # Project dependencies and build scripts
```
